SECCIÓN 1 — INTEGRANTE A

Información sobre el proyecto

Nexus nació de la necesidad de centralizar la comunicación y el seguimiento de tareas en equipos estudiantiles de alto rendimiento.

El problema

Antes de Nexus, el equipo coordinaba tareas repartidas entre WhatsApp, Google Drive y Trello: información dispersa, tareas duplicadas y falta de trazabilidad sobre quién hacía qué. Nexus unifica ese flujo en un solo lugar, pensado por y para equipos estudiantiles.

SECCIÓN 2 — INTEGRANTE B

Historia del proyecto

De una idea en un salón de clases a una plataforma funcional en producción.

Febrero 2026

Kickoff y planteamiento del problema

El equipo identificó la fragmentación de herramientas (WhatsApp + Drive + Trello) como principal obstáculo de productividad y propuso una solución unificada.

Marzo 2026

Sprint 1: diseño y arquitectura

Se definió la arquitectura MVC, el diseño de base de datos y los wireframes de alta fidelidad. Primer logro: aprobación del anteproyecto por el profesor.

Abril 2026

Sprint 2: módulo core

Autenticación, CRUD de tareas y tablero kanban funcionales. El equipo recibió mención honorífica en la expo interna de la facultad.

Mayo 2026

Sprint 3: integraciones

Conexión con GitHub API y generación automática de reportes PDF. El proyecto fue seleccionado para representar a UTSC en el Congreso Estudiantil de TI.

Junio 2026

Lanzamiento v1.0

Despliegue en producción con 40 usuarios piloto. Calificación promedio de 4.7/5 en encuesta de satisfacción.

SECCIÓN 3 — INTEGRANTE C

Tecnología utilizada

Stack moderno, abierto y orientado a la productividad del equipo.

🖥️

Frontend

HTML semántico + CSS custom properties + JavaScript vanilla. Sin frameworks para mantener el bundle por debajo de 50 KB.

⚙️

Backend

API REST con Express.js, autenticación JWT y middleware de logging. Desplegado en Railway con auto-deploy desde main.

api/tasks.js 
// Endpoint: obtener tareas de un proyecto
router.get('/projects/:id/tasks', verifyToken, async (req, res) => {
  try {
    const tasks = await db.query(
      `SELECT t.*, u.name AS assignee
         FROM tasks t
         LEFT JOIN users u ON t.assignee_id = u.id
        WHERE t.project_id = ?
        ORDER BY t.priority DESC`,
      [req.params.id]
    );
    res.json({ ok: true, data: tasks });
  } catch (err) {
    res.status(500).json({ ok: false, msg: err.message });
  }
});
